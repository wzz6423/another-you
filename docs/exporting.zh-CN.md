# 导出会话与用量

[English](exporting.md) | **简体中文**

打开会话后，点击 **导出会话**，可保存 UTF-8 Markdown 文件。完整历史加载完成且当前请求结束后才可导出。系统保存对话框用于选择位置；取消不会生成文件。

文件包含已存储的会话 ID、标题、状态、时间、关联应用、可用的分支来源、全部已加载的顺序问答、错误、可用快照元信息，以及能通过会话或请求 ID 明确关联的保留活动记录。原始文本放在代码块中保留。不会导出快照图片二进制、辅助功能树、模型思考原文或账户配置。应用已不再保留的内容不能通过导出恢复。元信息字段使用稳定的英文标识，问答保留原有语言。

在 **今天 → 用量概览** 选择 **24h / 7d / 15d / 30d**，再点击 **导出用量**。UTF-8 CSV 与界面使用相同的记录和参考时刻，包含范围起止边界；保存对话框打开后不会改变该次快照。

CSV 使用统一表头。`row_type` 区分 `summary`（汇总）、`model`（模型）、`reasoning`（思考深度）、`tool`（工具）、`request`（请求记录）与 `tool_call`（单次工具调用）。汇总和模型行包括请求数、已报告／未报告数、失败请求数及已报告 Token 总量；思考深度行统计请求数，工具行统计调用数。请求记录保留用量记录 ID、时间、来源、模型、结果、思考深度和已报告 Token 字段；工具调用用 `record_id` 关联对应记录。该 ID 是用量记录 ID，并非会话请求 ID。分析时不要将汇总行与明细行重复相加。

未报告的 Token 单元格留空；整个范围都未报告时，总量也留空。明确报告的零保留为 `0`。`usage_status` 分别为 `reported`、`unreported`、`partial` 或 `no_requests`。空范围仍导出时间范围与零请求数。所有单元格加引号，文本中的引号与换行按 CSV 标准转义；可能被电子表格解释成公式的文本前加单引号。时间使用 ISO 8601 UTC。

两种导出均在本地生成，只写入保存对话框选定的位置。导出内容可能包含私人问答、错误和应用名称，分享前请检查内容。
