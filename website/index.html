    从自己的 Mac 开始

    另一个你。
    就在这里开始。

    当前提供源码开发预览。
    先在熟悉的设备上，试试一种新的相处方式。

    macOS 14+Xcode 27+Node.js 22.19+

    源码已开源，当前从源码运行。

    1. 01

      准备运行环境

      准备 Xcode 27+、Node.js 22.19+ 和 npm。

    2. 02

      拉取源码，在本机启动

      在终端中执行以下命令。

    Terminal
    git clone https://github.com/wzz6423/another-you.git
cd another-you
make deps
make run

    1. 03

      按你的习惯，慢慢调整

      在设置中选择模型并连接账户，也可导入已有 Pi 配置。模型服务需单独准备。
